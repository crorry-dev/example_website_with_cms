Was dieses CMS kann

Alles, was du brauchst.
Nichts, was dich überfordert.

PHP-basiert, ohne Datenbank, ohne Framework. Perfekt für Anfänger.

Kein Framework nötig

Reines PHP. Kein Laravel, kein Symfony, kein Composer. Auf den Server laden und loslegen.

Admin-Dashboard

Seiten bearbeiten, Bilder hochladen, Farben ändern – alles über ein einfaches Webinterface.

JSON statt Datenbank

Alle Inhalte als einfache JSON-Dateien. Leicht zu verstehen, zu bearbeiten und zu sichern.

Styles anpassbar

Farben, Schriften und Akzente über das Admin-Panel ändern – ganz ohne CSS-Kenntnisse.

Responsive Design

Sieht auf Smartphone, Tablet und Desktop gleich gut aus. Automatisch.

Open Source

MIT-Lizenz. Frei nutzbar, erweiterbar und mit ausführlichen Kommentaren im Code.

Bereit für deine
Kunst-Website?

Clone das Repo, lade es auf deinen Server hoch und passe es über das Admin-Panel an. In der README findest du eine Schritt-für-Schritt-Anleitung.
